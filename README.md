# ⚔️ 이세계 판타지 RPG 🔮

마법사 / 전사로 전직하는 2D 탑다운 액션 RPG. 브라우저에서 `index.html`을 열면 바로 실행됩니다. (설치 불필요)

> 데모용 팀 프로젝트 — **팀 인원 2명** 기준으로 협업 규칙을 적용했습니다.

## 🎮 조작
| 동작 | 키 |
|---|---|
| 이동 | `W` `A` `S` `D` (대각선 가능) |
| 점프 / 회피 | `Space` |
| 대쉬 | `Q` |
| 달리기 | `Shift` |
| 스킬 | `R` 또는 `E` |
| 인벤토리 | `B` |
| 설정 | `ESC` |

## ✨ 핵심 시스템
- **성장 / 전직**: 몬스터 처치 → EXP → **5레벨 전직** (마법사=번개 / 전사=칼 내려찍기)
- **초광역 마법**: 마법사가 번개를 **7번** 쓰면 7번째에 초광역 번개 폭발
- **스킬 클래시**: 스킬이 부딪히면 WASD QTE (10초, 승리=공격 / 패배=기절)
- **몬스터 / 아이템**: 처치 시 검·마법봉·물약·EXP 드롭

## 👥 팀 구성 & 작업 분담 (2명)
| 팀원 | 담당 영역 | 작업 브랜치 |
|---|---|---|
| 팀원1 (김명찬) | 화면 · HUD · 렌더링 | `feature/hud-minimap` |
| 팀원2 | 전투 · 몬스터 · 아이템 | `feature/item-equip` |

## 🌿 브랜치 & 커밋 규칙
- `main` 브랜치는 **최종 결과물만** 저장 — 직접 푸시 금지
- 각자 `feature/...` 브랜치에서 작업 → **Pull Request** → 리더 확인 후 병합
- 작은 단위로 자주 커밋
- 커밋 메시지 형식: `feat:` `fix:` `style:` `docs:` + 무엇을 했는지
  - 예) `feat: 미니맵 추가`, `fix: 대각선 이동 속도 보정`
  - `수정`, `완료`, `진짜최종` 같은 메시지는 사용하지 않음

## 🔀 작업 순서
1. 최신 코드 받기 (`git pull`)
2. 자신의 `feature/...` 브랜치 생성
3. 맡은 영역만 수정
4. 작은 단위로 커밋 → 푸시
5. Pull Request 생성 → 리더 확인 → `main` 병합
